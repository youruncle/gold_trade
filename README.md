# 贵金属交易工作台

一个面向黄金、白银、铂金、钯金期货的研究与虚拟交易工作台。

## 功能

- 真实行情代理：本地后端请求 Yahoo Finance 的 COMEX/NYMEX 期货行情。
- 5 年日线历史数据与 1D 分钟级盘中数据。
- 折线图 / K线图切换，支持 hover 查看时间、价格和区间涨跌幅。
- 技术指标：MA20、MA60、RSI、30日年化波动。
- 决策辅助：趋势、动量、波动、支撑阻力、回撤与交易倾向。
- 信号雷达、交易计划、仓位风险预算。
- 简单策略回测：MA 趋势、RSI 均值回归、120日突破。
- 虚拟交易、持仓、成交、权益和盈亏统计。

## 运行

```bash
python3 server.py
```

打开：

```text
http://localhost:4173
```

## 数据说明

当前使用的是 Yahoo Finance 上的期货行情代码：

- `GC=F` 黄金期货
- `SI=F` 白银期货
- `PL=F` 铂金期货
- `PA=F` 钯金期货

这些不是伦敦金/伦敦银现货报价。若需要 `XAU/USD`、`XAG/USD` 现货，可在 `server.py` 中替换为 GoldAPI.io、Metals-API、Alpha Vantage 等正式数据源。
